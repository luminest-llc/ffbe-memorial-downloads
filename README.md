# FFBE Memorial English

[Download the latest Android APK](https://github.com/luminest-llc/ffbe-memorial-downloads/releases/latest)

A community fan translation of FINAL FANTASY BRAVE EXVIUS Memorial Edition, made to help preserve the game.

## Install or update

Download the APK and install it over your existing English edition. Keep your app data; do not uninstall the game or clear its storage. Completed game downloads carry forward.

On a fresh installation, the game downloads its files automatically. Interrupted downloads can resume.

## What's new in Patch 4

- Faster and more reliable game downloads.

- Your saved data and completed downloads are kept.

The translation and game content from Patch 3 are included.
